# Keeper

跨平台桌面宠物应用，内置桌宠：火史莱姆。

## 下载

安装包会在 GitHub Release 中发布：

[下载最新版 Keeper](https://github.com/204916223/Keeper/releases/latest)

如果还没有可下载文件，说明当前仓库还没有推送版本 tag。发布新版本：

```sh
git tag v1.0.0
git push origin v1.0.0
```

GitHub Actions 会自动构建 macOS、Windows、Linux 安装包并上传到 Release。

## 本地运行

```sh
npm install
npm start
```
